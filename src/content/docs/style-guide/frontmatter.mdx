Frontmatter is the YAML block at the top of every page. The build checks it against the schema in `src/content.config.ts` and fails on unknown or invalid fields.

```yaml
---
title: Connect Azure # Required. Sentence case.
description: Map an Azure subscription with the Reader role. # Required for search and social cards.
content_type: how-to # The page type. See Content types.
products: # Product ids from src/content/directory/.
  - connect
reviewed: 2026-11-10 # Last time a person checked the page, YYYY-MM-DD.
sidebar:
  order: 1 # Position within its folder (autogenerated groups only).
  label: Azure # Shorter label for the sidebar.
---
```

## All fields

| Field | Type | Use |
| --- | --- | --- |
| `title` | string | The page title and `<h1>`. Required. |
| `description` | string | The lead under the title, and the search and social description. |
| `content_type` | enum | The page type. See [Content types](/style-guide/content-types/). |
| `products` | string[] | Product ids from `src/content/directory/`. |
| `reviewed` | date | Last human review. |
| `difficulty` | `Beginner` · `Intermediate` · `Advanced` | Tutorials and learning paths. |
| `tags` | string[] | Free-form tags. |
| `template` | `doc` · `splash` | `splash` drops the page header and widens the column, for landing pages. |
| `sidebar` | object or `false` | `order`, `label`, `badge`, `hidden`; `false` hides the sidebar on this page. |
| `tableOfContents` | object or `false` | `false` hides "On this page". |
| `draft` | boolean | Builds the page but keeps it out of search and the sitemap. |
| `noindex` | boolean | Keeps the page out of search engines. |
| `banner` | object | A notice above the page: `content`, `type`. |
| `lastUpdated` | date | Overrides the date taken from git. |
| `prev`, `next` | string, object or `false` | Override the previous and next links. |
| `audience` | `human` | Marks a page written mainly for people rather than agents. |
