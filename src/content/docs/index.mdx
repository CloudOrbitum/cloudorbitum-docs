## Everything on the map is an API

<Tabs>
  <TabItem label="Graph">
    ### Query the resource graph

    Ask for resources, relationships and exposure in one query language. Results match what the live map shows, with the source of every fact attached.

    <CommandLine command='orb graph query "resources where exposed = true"' />

    [Write your first query](/graph/) · [Live map embeds](/graph/live-map-embeds/)
  </TabItem>
  <TabItem label="Agents">
    ### Hand a mission to an agent

    Agents such as Sentinel and Warden investigate alerts, propose fixes and open pull requests. Anything that changes your estate waits for approval.

    <CommandLine command='orb agents run sentinel --mission "explain alert alr-2041"' />

    [Start an agent](/agents/) · [Approvals and audit](/agents/approvals/)
  </TabItem>
  <TabItem label="Runbooks">
    ### Ship runbooks as code

    Write a runbook once, test it against a sandbox tenant, then let alerts trigger it.

    <CommandLine command="orb runbooks deploy ./runbooks/rotate-gateway-cert.yaml" />

    [Write a runbook](/agents/runbooks/)
  </TabItem>
  <TabItem label="Simulation lab">
    ### Rehearse incidents safely

    <Simulated /> Replay real failures against a copy of your estate and check that alerts, agents and runbooks respond the way you expect.

    <CommandLine command="orb lab simulations create --from-incident inc-117" />

    [Run a simulation](/simulation-lab/) · [Sandbox tenants](/simulation-lab/sandbox-tenants/)
  </TabItem>
</Tabs>
